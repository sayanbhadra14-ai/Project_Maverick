M&A Target Screening & Valuation Analysis

This project replicates the front-end workflow of a real M&A deal, covering target identification, financial screening, and valuation benchmarking. The analysis was completed using SQL, Power BI, and Excel, following a structured, consulting-style approach.

📌 Project Overview

The objective was to build a data-driven M&A target pipeline by:

- Mapping the universe of potential acquisition targets

- Applying financial & strategic filters to shortlist viable companies

- Running valuation benchmarks (CCA, PTA, rule-of-thumb multiples)

- Visualizing insights through a Power BI dashboard

- Recommending the most suitable target based on data + logic

This workflow aligns with real pre–LOI (Letter of Intent) steps used in investment banking and corporate M&A teams.

🛠 Tools Used

SQL → Data cleaning, filtering, segmentation

Power BI → KPIs, charts, dashboards, valuation visuals

Excel → Financial calculations, valuation tables
